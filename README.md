# 🏦 Bank Analysis Project | Excel & Power BI

## 1. Project Overview and Objective

This Bank Analysis project focuses on data cleaning, transformation, and analysis using Microsoft Excel and Power BI.

The project aims to transform raw banking data into meaningful business insights through data preprocessing, exploratory data analysis, data modelling, DAX calculations, and interactive dashboard development.

The main objective is to understand banking performance, analyze customer financial information, and support data-driven business decision-making.

## 2. Data Sources

- **Dataset:** Banking Dataset
- **Source:** Dataset provided for academic analysis
- **Domain:** Banking and Financial Analytics
- **Tools:** Microsoft Excel and Power BI

## 3. Problem Statement

The banking industry generates large amounts of customer and financial data. Analyzing this data helps financial institutions understand customer behavior, banking relationships, financial performance, and investment patterns.

This project aims to:

- Analyze banking customer information and financial activities.
- Identify patterns in customer banking relationships.
- Understand customer segmentation and financial performance.
- Explore banking metrics and trends.
- Develop interactive dashboards for business decision-making.
